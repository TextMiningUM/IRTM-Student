Each tutorial has its own folder for your work:

- **Tutorial_01_Tokenization** - Text tokenization and normalization

- **Tutorial_03_Measuring_Quality** - Evaluation metrics, precision, recall
- **Tutorial_04_Dense_Retrieval** - Semantic search with embeddings
- **Tutorial_05_Search_Engines** - Indexing and ranking systems
- **Tutorial_06_Structured_Representations_1** - Information extraction (Part 1)
- **Tutorial_07_Structured_Representations_2** - Information extraction (Part 2)
- **Tutorial_08_Detecting_Patterns_1** - Text classification and clustering (Part 1)
- **Tutorial_09_Detecting_Patterns_2** - Text classification and clustering (Part 2)
- **Tutorial_10_Conversational_Search_Basics** - Conversational IR fundamentals
- **Tutorial_11_Conversational_Search_Facts** - Fact-based conversational systems
- **Tutorial_12_Agents** - Autonomous AI agents

## 📋 Workflow

1. **Copy** the assignment notebook from `Assignments/` to the appropriate `Submitted Work/Tutorial_XX/` folder
2. **Complete** the exercises in your copy
3. **Save** your work regularly
4. **Submit** according to course instructions (typically via JupyterHub or file upload)

## 💡 Tips

- ✅ Always work on a **copy** of the assignment, not the original
- ✅ Keep original assignments in `Assignments/` folder untouched
- ✅ Name your files clearly (e.g., `Tutorial_01_YourName.ipynb`)
- ✅ Run all cells and verify output before submission
- ✅ Check that all exercises are completed
- ✅ Include comments explaining your approach

## ⚠️ Before Submitting

- [ ] All code cells run without errors
- [ ] All exercises have solutions (no `raise NotImplementedError()`)
- [ ] Markdown answers are complete
- [ ] Output is visible for all cells
- [ ] File is saved with your name
- [ ] Submitted to correct assignment folder on JupyterHub
